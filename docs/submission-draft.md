## 项目介绍（表单第 2 项）

FlameID 是为 Binance Agent ID 持有者做的链上每日打卡游戏：
每天打卡一次，连续打卡积累 streak，断签则重置；打卡满 7 / 14 / 30 /
60 / 100 天可领取灵魂绑定徽章（链上 SVG 艺术，不可转让、不可出售）。

**与众不同的地方（放在开头）：**

- **护盾（Shield）：** 邀请好友，好友连续打卡满 3 天，邀请人获得 1 个护盾
  （上限 3 个）。漏签恰好 1 天时护盾自动消耗、streak 不断；刷量没有意义
  ——推荐只有在被邀请人真的连续打卡 3 天后才算数，而且被邀请人必须持有
  不可转让的 Agent ID。
- **Genesis 徽章：** 上线后前 7 天内打卡即可领取，窗口关闭后永久无法领取。
- **信誉分 + 开放 API：** `scoreOf(address)`（满分 140 分：当前 streak、
  总打卡数、有效推荐、账号年龄、护盾数）与 `isActiveAgent(address,
  minScore)` 都是纯 view 函数，任何其他 dApp 都可以直接在链上调用，
  用来给真实活跃的 Agent 做功能门禁——这是一个可组合的基础设施，
  不只是一个打卡页面。
- **Season 1（赛季）：** 上线起 14 天赛季，至 2026-12-09 08:00 UTC 结束。
  赛季内任意一周 7 天全勤可领 Survivor 徽章；赛季 streak 前 3 名可在赛季
  结束后领 Champion 徽章。前 3 名由合约链上维护，前端无需扫描全部钱包。
- **可分享的 streak 名片：** 每个 Agent ID 持有者都有公开主页
  `/agent/<名字>.ai`，直接读合约显示 streak、徽章、护盾、推荐数与信誉分，
  无需连接钱包即可查看；名字完全在链上解析
  （`ownerOf(keccak256(label))`）。

## Agent ID 的使用方式（表单相关项）

- 每次打卡与领徽章时，合约读取 SPACE ID Agent ID 注册表
  （`0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F`）的 `balanceOf`，
  只有持有 Agent ID 的钱包才能使用；Agent ID 不可转让，无法冒充。
- 团队无管理权限：合约没有 owner、没有管理员、没有费用、没有代币、
  不可升级；所有交易 value 均为 0，用户只付 gas。
- 徽章是灵魂绑定 ERC-721，转账与授权都会 revert。
- 网站不要求用户扫描登录二维码、不保存任何会话、不索取助记词/私钥。
